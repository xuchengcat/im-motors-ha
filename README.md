# 智己汽车 Home Assistant 集成

[![Validation](https://github.com/xuchengcat/im-motors-ha/actions/workflows/validate.yaml/badge.svg)](https://github.com/xuchengcat/im-motors-ha/actions/workflows/validate.yaml)

在 Home Assistant 中查看智己车况、车辆位置、行程和轨迹，并管理账号认证。运行不依赖手机、ADB 或 Windows。

当前仓库开发版为 **v0.9.0b1**，新增本地充电与加油档案，支持主账号官方行程每日归档与随机自动签到。代码推送与 HACS Release 分开：安装前核对所选发行版，旧版可能没有这些功能。完整入口见[文档导航](docs/README.md)。

## 先选对账号和功能

| 功能 | 主账号 | 授权账号（副账号） |
|---|---|---|
| 电量、续航、里程、胎压、门窗、充电与车辆位置 | 按服务端实际返回展示 | 按授权范围展示 |
| 官方行程日历与轨迹 | 可开启，每天03:00增量归档 | 不调用车主日历接口 |
| HA 自行记录未来行程 | 不启用 | 可开启，复用车况采样 |
| 每日随机自动签到 | 可开启，02:00–06:00 | 不启用 |
| 实验性车辆控制 | 取决于首次配置的运行模式与实际权限 | 取决于首次配置的运行模式与实际权限 |

**账号类型**与**运行模式**是两个设置。账号类型可在选项中修改；“只读 / 全功能”只在首次配置时选择，之后不可切换，旧配置固定为只读。选择主账号不会改变服务端车主权限。默认关闭行程归档、本地记录和自动签到，按需开启；签到是社区操作，开启它不会开启车控。

## 安装与首次登录

要求 **Home Assistant 2026.2 或更高版本**，已在 Linux HA 2026.2.3 验证。

1. 在 HACS 的 **⋮ → 自定义存储库** 添加 `https://github.com/xuchengcat/im-motors-ha`，类型选 **Integration / 集成**。
2. 搜索 **智己汽车**，下载所需版本并重启 HA。
3. 打开 **设置 → 设备与服务 → 添加集成 → 智己汽车**，选择手机号与短信登录。
4. 选择账号类型、运行模式和车况查询间隔，填写中国大陆手机号，提交后输入短信验证码。
5. 登录完成后，在该集成的 **配置 / 选项** 中开启需要的行程或签到功能。

无需手工准备协议参数或密钥；首次短信登录会在本地建立加密存储。全功能模式涉及实验性车控，选择前阅读[车控说明](docs/guides/vehicle-control.md)。

手工安装可从 [Releases](https://github.com/xuchengcat/im-motors-ha/releases) 下载 `im_motors.zip`，解压到 `/config/custom_components/im_motors/` 后重启。开发版可从仓库复制该目录，避免产生重复嵌套目录。HACS 运行包与完整工程包的区别见[安装指南](docs/guides/installation.md)。

## 开始使用

### 查看车况与地图位置

设备页提供电量、续航、总里程、胎压胎温、温度、门窗和充电实体。“车辆位置”可加入 HA 地图卡片。车况默认每60分钟查询，最短5分钟；设备上的 **立即重新查询车况** 按钮可主动请求云端。

总里程按账号类型读取：主账号使用当天行程H5的 `totalMileage`，授权账号使用车辆健康/诊断接口的 `mileage`。保留原实体与统计历史，按车况查询间隔更新，独立于官方行程归档开关。健康数据可能滞后，可在实体属性查看来源更新时间。[总里程来源与限制](docs/guides/odometer.md)

云端可能返回缓存快照，查询并不保证获得即时位置，也可能唤醒车辆。每分钟的认证检查不代表每分钟查询车况。字段缺失时保持 unknown / unavailable，不用零值替代。具体来源见[数据对应关系](docs/reference/data-mapping.md)。

### 充电与加油档案

侧边栏“智己行程”新增充电记录，复用原有车况查询，主/副账号均可开启；记录观测起止、电量和地点，支持按账单补填充电量、费用、手工记账和导出。燃油功能仅对已确认具有 `HYBRID_ELECTRIC` 能力的车辆展示，纯电不创建相关实体；加油候选需人工确认。默认关闭自动记录，不增加智己查询，不把 SOC 差或单位待定的 `chargedPower` 当作度数。[完整说明](docs/guides/energy-history.md)

### 主账号：官方行程归档

在选项中选择 **主账号**，开启 **每日自动归档官方行程（仅主账号）**。首次启用会补齐近60天；之后每天 **03:00（HA 时区）**检查缺失或变化的行程，启动时补跑当天尚未执行的任务。

使用 HA 管理员账号打开侧边栏 **智己行程**（`/im-motors-trips`），选择账号与车辆。蓝色日期代表本地已有行程，点击日期、查询列表、打开轨迹均只读取本地数据库。主账号轨迹默认隐藏中间点标识，可勾选 **显示轨迹点**。

已归档历史长期保留，不随官方60天窗口或 HA Recorder 清理而删除。需要主动补查时使用 **手动补同步（最多31天）**。当前仅支持关联一辆车的官方行程账号。[完整使用与归档规则](docs/guides/official-trip-history.md)

### 授权账号：自行记录行程

在选项中选择 **授权账号**，开启 **根据 HA 车况自行记录行程**。按车辆启动至熄火分段，复用现有车况采样，不额外高频查询。只能记录开启后取得的数据，无法补回未采集的过去轨迹；精度受查询间隔、云端缓存和停车定位证据影响。[本地记录指南](docs/guides/local-trip-recording.md)

### 主账号：每日自动签到

在选项中开启 **每日随机自动签到（主账号，02:00–06:00）**。每天在 HA 时区的该窗口内选一个随机秒：先查官方信息与签到记录，已签到跳过，未签到才提交并回查。

随机计划重启后保持，窗口内可恢复错过的计划，06:00以后不在白天补跑。设备的 **每日签到** 实体显示最近结果与 `next_run`。结果不明不盲目重复提交，不自动补签、领取盲盒或参与额外活动。[配置、结果说明与实测边界](docs/guides/daily-checkin.md)

### 地图和高德 Key

**画地图和轨迹不需要高德 API Key。** 地图使用 HA 组件，底图需要网络；智己坐标在本地转换后显示。

仅在需要把起终点坐标补成文字地址时，才在账号选项中填写高德 **Web服务 API Key**，再在“智己行程”点击 **补全历史地址**。Key 按账号加密保存；留空保留，勾选清除才删除。副账号的 Key 不会自动共享给主账号，但可在两个账号中填写同一个 Key。[地址与地图指南](docs/guides/maps-and-addresses.md)

## 认证、备份与维护

- **自动续期**：按服务端建议时间刷新令牌，不需要固定每月短信登录；已过期、被撤销或服务端要求验证时需要重新认证。新短信登录实验性使用 WXAPP，旧 APP 会话不会因升级自动切换。[认证与双登录](docs/guides/authentication.md)
- **备份**：同时保留完整账号数据目录和匹配密钥，官方行程库与本地记录库独立保存。SQLite 行程库包含位置历史，不能当作脱敏文件分享。[备份与恢复](docs/guides/backup-and-recovery.md)
- **排查**：先区分云端缓存、认证失效、请求退避、未归档与地址待补全。[常见问题](docs/guides/troubleshooting.md)
- **问题反馈**：提供 HA 版本、集成版本、错误类别与脱敏诊断，勿附手机号、VIN、令牌、密钥或完整行程库。[提交问题](https://github.com/xuchengcat/im-motors-ha/issues)

### 字段解释边界

`period.bmsPackSOH` **尚不能确认是电池健康度或百分比**，此前的“电池健康度”解释已撤回。它保留为默认启用、无单位的英文原始字段，不用于判断衰减或故障。173项英文原始诊断字段统一标记“其他”，用户手动禁用的选择保留。`chargedPower` 单位也尚未确认，不标为 kWh。[原始字段及确认状态](docs/reference/other-fields.md)

```text
  frontend/                   智己行程面板
  pyim_china/                 认证、签名和加密存储

docs/                         使用指南、字段参考、开发资料和历史说明
tests/                        合成数据与 HA 回归测试
tools/                        打包、凭据审计和离线恢复工具
docker/                       旧外置路径的手工测试模板
dist/                         本机构建输出（不提交 Git）
```

```sh
python -m pip install -r requirements-test.txt
```

测试阻止真实 HTTPS 连接，使用合成账号、临时加密存储与 mock HTTP。完整工程包包含递归整理后的文档与工具；HACS 运行包只含集成代码与许可。[开发与目录约定](docs/development/contributing.md) · [版本记录](CHANGELOG.md)

本项目为非官方集成，与车辆厂商没有关联。当前映射主要依据 LS6 云端响应、App 逻辑与页面核对，其他车型及长期接口稳定性仍需验证。代码许可见 [LICENSE](LICENSE)。
