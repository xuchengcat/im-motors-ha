# 安装、配置与升级

[返回文档导航](../README.md)

要求 Home Assistant **2026.2或更高版本**。已在 Linux HA 2026.2.3上测试；HA OS、其他车型与不同部署环境仍需各自验证。

## 通过 HACS 安装

1. 打开 HACS，选择 **⋮ → 自定义存储库**。
2. 添加 `https://github.com/xuchengcat/im-motors-ha`，类型选择 **Integration / 集成**。
3. 搜索 **智己汽车**，核对版本后下载，重启 HA。
4. 打开 **设置 → 设备与服务 → 添加集成 → 智己汽车**。

这是自定义仓库安装，不代表已收录 HACS 默认列表。代码推送到 main 不等于已发布对应 Release；仓库开发版功能可能不在所选发行版中。HACS操作另见[官方自定义仓库说明](https://www.hacs.dev/docs/faq/custom_repositories/)。

## 手工安装开发版

从仓库取得 `custom_components/im_motors/`，将该目录完整放入 HA 配置目录：

```text
/config/custom_components/im_motors/manifest.json
/config/custom_components/im_motors/__init__.py
/config/custom_components/im_motors/pyim_china/
/config/custom_components/im_motors/frontend/
```

确认不是 `/config/custom_components/im_motors/im_motors/` 这样的重复嵌套目录，然后重启 HA。不要把完整工程 ZIP 的所有文件直接解压进集成目录。

| 文件包 | 用途 |
|---|---|
| `im_motors.zip` | HACS和手工安装使用的运行包，内容直接放入 `custom_components/im_motors/` |
| `im_motors_ha-版本.zip` | 完整工程，含测试、工具和指导文档；适合开发及离线恢复 |

## 首次手机号登录

1. 选择 **手机号与短信登录**，填写中国大陆手机号。
2. 选择 **主账号 / 授权账号**。这是集成使用方式，不会授予实际车主权限。
3. 选择 **只读（默认）/ 全功能**。模式在首次配置后固定，重新配置、重新认证及修改账号类型不会切换它。选择全功能前阅读[车控说明](vehicle-control.md)。
4. 设置车况查询间隔，默认60分钟，最短5分钟。提交后输入收到的验证码。
5. 登录完成后首次读取关联车辆和车况。到集成的 **配置 / 选项** 中开启需要的行程或签到功能。

无需自行准备 `production.imvault`、设备身份或密钥；新短信登录在本地创建加密存储。手机号和验证码不保存到 HA 配置条目。

需要新验证码时勾选 **重新发送验证码**，验证码可以留空；重发至少间隔60秒。本地验证码流程有效期10分钟，服务端可能更早过期。关闭页面后，重新输入同一手机号可以继续有效流程。图形验证码、风控或额外绑定暂未在 HA 界面实现，出现时按提示停止处理。

## 配置选项

| 选项 | 使用方式 |
|---|---|
| 账号类型 | 旧配置默认授权账号；修改后只启用该角色支持的行程、签到功能 |
| 根据 HA 车况自行记录行程 | 授权账号可开启；开启后记录未来行程 |
| 每日自动归档官方行程 | 主账号可开启；每天03:00归档，展示只读本地 |
| 每日随机自动签到 | 主账号可开启；每天02:00–06:00随机检查和签到 |
| 车况查询间隔 | 默认60分钟，最短5分钟；不决定认证检查或每日任务时间 |
| 高德 Web服务 Key | 可选，仅补全文字地址；留空保留已存值，勾选清除才删除 |

时间均按 **HA 配置时区**。每日任务由 HA 集成执行，不需要另外建立 cron 或 HA 自动化。

## 更新已有配置

先按[备份指南](backup-and-recovery.md)备份，再通过 HACS 更新或完整替换代码目录，重启 HA。HACS只更新代码，不替换账号密钥或数据库。

旧的外置数据目录、密钥挂载、已有设备身份和实体继续沿用，不会自动迁移或重建。旧 APP 会话不会自动变成 WXAPP；如需切换，通过重新配置完成一次新短信登录，见[认证管理](authentication.md)。

升级后如前端仍显示旧页面，刷新“智己行程”或清理该站点前端缓存，再核对实际加载的集成版本。不要通过删除账号存储解决页面缓存问题。

## 导入已有加密会话

此入口面向旧账号迁移和高级配置：选择 **导入已有加密会话**，填写数据目录及匹配密钥的绝对路径。目录中须有同一客户端身份的 `session.imvault`、`device.imvault`；`production.imvault` 可选。导入先离线校验，首次加载再请求关联车辆和车况。

路径必须是 HA 进程能访问的路径。Container中的 `/config` 与宿主机路径不同，应填写容器内路径；密钥与账号目录的文件所有者须允许 HA 读写会话。旧挂载示例见[开发指南](../development/contributing.md)。
