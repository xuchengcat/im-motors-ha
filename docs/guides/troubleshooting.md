# 常见问题与故障排查

[返回文档导航](../README.md)

先核对 **HA版本、实际安装的集成版本、账号类型、运行模式和已开启选项**。开发分支、HACS发行版与本机已加载代码可能不是同一版本。

| 现象 | 检查与处理 |
|---|---|
| HACS没有README所述功能 | 核对所选Release版本；main推送不代表已发布。开发版手工安装后需重启HA |
| 更新后行程界面仍旧 | 刷新页面，必要时清理站点前端缓存；勿删除账号数据 |
| 手机或HA退出登录 | 查看认证提示；WXAPP仅验证过短期共存，必要时用原账号重新认证 |
| 账号提示另一操作正在进行 | 等待同账号操作释放锁，不并行启动刷新，不复制会话绕过 |
| 车况长时间不变 | 云端可能缓存；检查查询间隔和车辆休眠状态，可按需点“立即重新查询车况” |
| 实体unknown / unavailable | 可能未返回、null、格式不支持或认证故障；实体存在不保证有读数，勿填零 |
| 主账号没有本地记录 | 主账号使用官方归档，不使用副账号的HA采样记录 |
| 日历没有蓝色日期 | 蓝色只代表本地已归档行程；检查归档选项、进度和最近成功日期，必要时手动补同步 |
| 无法补回60天以前未归档的行程 | 只能保存官方仍可读取的数据，无法恢复厂商已删除且本地未保存的历史 |
| 旧的本地历史仍能查看 | 正常。本地归档长期保留，不随远程窗口删除 |
| 官方历史返回非车主/权限错误 | 账号类型选择不改变真实权限；检查实际车主账号，目前官方归档仅支持关联一辆车 |
| 轨迹有线但没有地址 | 地图无需Key；文字地址需要有效高德Web服务Key，再执行补全 |
| 本地起终点待确认 | 等待稳定停车定位，地址Key不能替代缺失位置证据 |
| 官方单点没有时间 | 原接口可能未提供，集成保持未知 |
| 签到实体没有出现 | 确认主账号并开启随机自动签到，保存后等集成重载 |
| 06:00后启用签到未立即执行 | 正常，只安排下一天；不是白天补签任务 |
| 签到error | 查询、认证或日期校验失败，当天不循环重试，查看App与HA认证状态 |
| 签到unknown | 提交结果不明或回查未确认，先看App记录，不强制再次POST或删除提交状态 |
| bmsPackSOH没有百分比单位 | 当前含义尚未确认，仅作英文原始诊断字段 |

## 网络退避与认证停止

临时GET网络错误与HTTP 408/429/5xx依次退避1、2、4、8分钟，之后最长每15分钟重试。重启或手动查询不会绕过退避；等待车况重试时仍维护可用认证。此规则不代表官方行程归档或签到也按相同频率重试，二者遵守各自每日执行规则。

认证失效、未决刷新、VIN不一致及未知写请求结果按[备份与恢复指南](backup-and-recovery.md)排查。不要删除pending、改本机有效期或以反复短信登录解决普通网络错误。

## 反馈问题时提供

提供HA版本、集成版本、账号类型、发生时间和时区、操作步骤、错误类别，以及HA脱敏诊断。截图也请去掉手机号、VIN、车牌和位置。不要附账号目录、密钥、完整服务端响应或行程数据库。
