# 账号认证、自动续期与手机共存

[返回文档导航](../README.md)

## 两个独立设置

| 设置 | 决定什么 | 后续能否修改 |
|---|---|---|
| 主账号 / 授权账号 | 官方行程归档、本地记录与签到的适用功能 | 可在选项中修改 |
| 只读 / 全功能 | 是否允许实验性车辆控制 | 首次配置后固定 |

旧配置默认按授权账号、只读模式处理。把副账号选成主账号不会改变官方权限。

## 令牌会自动续期吗

会。HA每分钟检查本地会话元数据，**到服务端建议刷新时间才发送刷新请求**。设备中的“账号凭据到期时间”和“建议刷新时间”来自服务端；刷新成功后原子保存新令牌和新的时间。

不需要固定每月短信登录，也不应把某次返回的有效期当成永久规则。服务端可能撤销会话、改变期限或要求验证；HA长期离线超过有效期也可能需要重新登录。车况默认60分钟查询、元数据缓存30分钟，与每分钟的本地认证检查分开。

## WXAPP 与手机双登录

新发起的短信登录实验性使用 `clientType=WXAPP`，客户端类型加密保存，刷新及离线恢复沿用该类型。已有 APP 会话或旧短信流程保持 APP，不能直接修改旧令牌旁边的类型字段来切换。

如要切换，打开集成 **重新配置 → 手机号与短信登录**，用原账号完成一次新登录。已验证主账号WXAPP登录、读取、刷新，以及手机App保持登录时的短期共存；不保证其他账号、长期运行或手机重新登录后的行为。[详细验证边界](../development/wxapp-validation.md)

## 何时需要重新登录

| 情况 | 处理 |
|---|---|
| 会话有效，到建议刷新时间 | 交由集成自动刷新，无需短信 |
| 临时网络错误或账号锁被占用 | 等待相应重试或释放锁，不因此重发短信 |
| 认证过期、服务端撤销令牌 | 在 HA 提示的重新认证入口用原账号登录 |
| 未决登录/刷新请求，结果未知 | 先核查保留状态，按恢复流程处理 |
| 服务端要求图形验证、风控或绑定 | 当前HA界面不支持额外交互，停止并查看具体提示 |

重新认证保留账号关联、运行模式与原配置。新增其他账号应从“添加集成”进入。不要删除 pending 文件、修改过期时间或让多份过时会话轮流刷新同一账号。

## 与本机社区发帖客户端共用认证

本机 `im-community-posting` skill 已支持从 HA 账号配置定位同一份加密存储，复用WXAPP会话、设备身份及 `account.lock`，按需刷新并写回。它是独立安装的本机工具，**不包含在HACS包内**，安装本集成不会自动安装或启用发帖。

共用的是同一数据目录，不是复制token。双方须访问同一真实挂载目录与锁文件；不要给两个独立存储复制旧会话。发帖仍遵守该工具的稿件审阅与发布授权流程。

## 本地存储

账号令牌、设备身份、登录回执和高德Key加密保存，HA配置条目主要保存路径、身份哈希及功能选项。新短信登录通常位于 `/config/.storage/im_motors/`，导入账号或定制部署可能使用其他目录；备份以实际配置路径为准。[存储与恢复指南](backup-and-recovery.md)
