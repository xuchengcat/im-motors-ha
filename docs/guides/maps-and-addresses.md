# 地图、轨迹与文字地址

[返回文档导航](../README.md)

## 哪些功能需要高德 Key

| 功能 | 是否需要高德Key |
|---|---|
| 车辆位置加入HA地图卡片 | 不需要 |
| “智己行程”画起终点和轨迹 | 不需要 |
| 点击轨迹点、查看详情表格 | 不需要 |
| 把起终点坐标补成地址和附近POI | 需要可用的高德Web服务Key |

地图使用HA组件，底图需要网络。没有Key仍能显示坐标和路线；Key只用于服务器端逆地理编码，不提供给前端地图。

## 配置并补全地址

1. 准备支持逆地理编码的高德 **Web服务 API Key**，检查配额和IP限制；不是地图JS Key。
2. 打开对应智己账号的 **配置 / 选项**，填写Key并保存。
3. 刷新“智己行程”，选择该账号，点击 **补全历史地址**。主账号后续归档也会尝试补全缺失地址。

Key按账号加密保存在 `trip-settings.imvault`。输入框留空保留旧值，只有勾选清除才删除。主、副账号之间不会自动共用Key，可分别填写同一个有效Key。失败时保留原坐标与历史，不覆盖官方轨迹。

## 起终点“待确认”与“待补全”不同

- **待确认**：本地采样还没有足够稳定停车证据，不能把第一或最后一个原始点当成已确认起终点。填写Key不能补造缺失定位，见[本地记录规则](local-trip-recording.md)。
- **已有坐标、文字地址待补全**：位置已经存在，但未取得地址文字，可检查Key并执行补全。
- **轨迹点时间未知**：官方详情可能未提供单点时间，不按起止时间插值。地址接口不能补回时间或缺失轨迹。

主账号默认画完整轨迹线与起终点，隐藏中间点标识；勾选“显示轨迹点”可恢复。官方轨迹按服务端顺序保存，HA自行记录则受原车况查询间隔影响，不进行道路规划来冒充实测路线。

地图使用WGS-84；已支持的App坐标按现有GCJ-02链路转换。未知坐标格式不会强行展示；相关证据见[字段映射](../reference/data-mapping.md)。
