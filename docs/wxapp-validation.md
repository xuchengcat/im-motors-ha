# WXAPP 登录验证与兼容性

新发起的 HA 短信登录使用实验性 `clientType=WXAPP`。客户端类型加密保存在登录状态与会话中，令牌刷新及离线恢复沿用同一类型。

## 已验证

- 主账号短信登录被服务端接受，并返回可用会话。
- 只读车辆与车况查询成功。
- 使用同一 WXAPP 客户端类型刷新令牌成功，刷新后查询继续可用。
- 手机 App 保持登录时，HA 会话仍能读取车况，完成短期双端共存验证。
- 主账号官方行车日历和轨迹接口可使用该会话，见[官方历史行程说明](official-trip-history.md)。

这些结果不保证长期运行、手机重新登录后或其他账号的共存行为；厂商接口仍可能变化。

## 旧会话与升级

升级前的 APP 会话、升级前已发送的短信流程没有客户端类型字段时，默认保留 APP。切换应通过“重新配置 → 手机号与短信登录”完成一次新登录，不能只修改旧令牌旁的类型字段。

账号类型由用户手动选择，旧配置默认授权账号；该选择只决定集成使用的行程来源，不会改变服务端权限。主账号停用基于 HA 车况的本地采集，已有历史保留；官方历史使用独立归档库。签到尚未开发。

## 凭据管理

账号令牌、设备身份、登录响应和高德 Key 保存在本地加密存储中。Git 仓库、运行包及本文均不包含个人账号凭据、私有Key或个人行程正文。发布的通用协议参数不能解密用户的账号文件。导入或迁移会话时，请同时保留匹配的数据目录与密钥，避免多个运行实例并行刷新同一账号的旧凭据副本。
